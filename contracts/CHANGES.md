# Reconciliation record

The original 1.0.0 schemas moved from contracts/v1/archive/1.0.0 to contracts/v1. The active 2.0.0-draft.1 schemas moved unchanged from contracts/v1 to contracts/v2. Resolve the major directory and then require the exact wire constant and URN. Existing manifests and their byte hashes need no rewrite. A v1 requirement bundle still needs separately sourced execution evidence before it can represent a v2 campaign.

Schema validation checks types, structure, dialect, version and enumerations. Semantic validation resolves IDs, verifies bytes, rejects duplicate execution IDs and unexpected observations, and compares fixture report fields with observations. The fixture adapter is a simple authored JSON format. It provides no evidence of upstream adapter interoperability.

The policy version binds exact policy bytes. The mandatory matrix must be anchored by trusted policy or source configuration before evaluating it. The examples use two required executions. BLOCKED requires a complete failed mandatory observation corroborated independently of the bundle. Fixture verification matches a repository-controlled receipt by campaign, execution and artifact digest. Complete uncorroborated failures and partial failures yield insufficient evidence. The same corroboration is required for passing observations to establish eligibility. Every missing, skipped, errored, unavailable or partial required result without a confirmed failure yields INCONCLUSIVE. Only complete verified passes yield ELIGIBLE. Retain every adverse reason, sorted by execution ID then code, with sorted artifact IDs. Compare canonical content excluding evaluated_at; digest the original evidence manifest bytes. Rejected ingestion yields no decision. Identity examples compare original bytes under the same immutable campaign ID.

Only samples/model-visible contains model-input examples. The contract permits advisory statements and evidence IDs. The eventual tool layer must enforce bounded read-only access, resolve every citation in its authorized campaign and redact raw content. Claim support requires separate grading. Unknown labels, internal prompts, raw logs and grader outputs must stay outside this interface.

All semantic campaign cases are authored examples with synthetic timestamps. They neither certify a trusted source nor measure application behavior. Human review should confirm policy treatment of errors and incomplete failures, the budget/parameter fields needed by the chosen model, and the breaking draft version before baseline creation.

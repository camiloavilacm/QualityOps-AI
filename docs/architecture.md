# Architecture

QualityOps AI is structured as four isolated Python capabilities plus a static React/TypeScript presentation layer, connected through frozen, versioned JSON Schema Draft 2020-12 contracts in `contracts/v2/`.

## Frozen Contracts (`contracts/v2/`)

| Contract | Wire Version | Purpose |
|---|---|---|
| `evidence.schema.json` | `2.0.0-draft.1` | Normalized campaign bundle with provenance, expected matrix, observed outcomes, observation completeness, and SHA-256 artifact digests. |
| `gate-decision.schema.json` | `2.0.0-draft.1` | Deterministic release decision (`ELIGIBLE`, `BLOCKED`, `INCONCLUSIVE`), canonical input digests, policy version, and full reason list. |
| `investigation.schema.json` | `2.0.0-draft.1` | Advisory AI failure investigation (`DIAGNOSED`, `INCONCLUSIVE`, `ERROR`), cited claims, uncertainties, model/prompt provenance, usage, cost, and latency. |

## Module Boundaries

### 1. Evidence Ingestion (`backend/ingestion/`)
- Reads upstream campaign manifests via `O_DIRECTORY | O_NOFOLLOW` descriptor-anchored file reads (`importer.py`) to prevent path traversal and symlink escapes.
- Enforces file, artifact, and bundle size caps, rejects duplicate JSON keys and non-finite numbers, and verifies SHA-256 digests before atomic publication.
- Supports idempotent re-import of identical bytes and rejects conflicting bytes under the same immutable ID.

### 2. Pure Deterministic Release Gate (`backend/gate/`)
- `policy.py` (`decide`) has **zero imports** and evaluates validated evidence solely against an independently supplied policy matrix and trusted source receipts (`replay.py`).
- Precedence is `BLOCKED > INCONCLUSIVE > ELIGIBLE`, while preserving every applicable reason code (`REQUIRED_FAILURE` and `INSUFFICIENT_EVIDENCE` together).
- Verified by static AST tests (`tests/test_vertical_slice.py`) to have zero imports of `backend.investigator`, `evaluators`, AWS SDKs, or networking libraries.

### 3. Read-Only AI Failure Investigator (`backend/investigator/`)
- Implements a bounded raw Amazon Bedrock Converse loop (`investigator.py`) behind an injectable `Backend` / `BedrockTransport` abstraction (`total_max_attempts=1`, bounded connect/read timeouts, per-request and total investigation deadlines `<= 20s`).
- Exposes a single read-only tool (`read_evidence`) scoped to an allowlist of sanitized observation IDs for the selected campaign.
- Enforces pre-call cost reservation (`<= $0.10`), max 4 invocations, 256 max output tokens per call, and strict structured JSON output validation (`DIAGNOSED` claims must match a complete cited observation verbatim; operational failures return schema-valid `ERROR`).

### 4. Independent Evaluation Engine (`evaluators/`)
- Separates model-visible projections (`evaluators/model_visible/corpus-v1.json`, pinned by SHA-256 in `projection.py`) from held-out ground truth (`evaluators/ground_truth/corpus-v1.json`, pinned by SHA-256 in `evaluate.py`).
- Replays authored or recorded 3-trial runs deterministically, computing diagnosis accuracy, citation validity, claim support, abstention, safety violations, `pass@3` / `pass^3`, latency/cost percentiles, and `SPEC.md` §9 baseline-vs-candidate promotion checks.

### 5. Sanitized Static Dashboard (`frontend/`)
- Static React + TypeScript SPA built with Vite (`--base=./`) for zero-backend hosting (e.g., GitHub Pages).
- Consumes only allowlisted, sanitized JSON exports generated by deterministic scripts (`frontend/scripts/export_mixed.py`, `frontend/scripts/export_showcase.py`) and the sanitized live benchmark summary (`frontend/src/live-evaluation.json`).
- Never reads raw evidence artifacts, source receipts, held-out ground truth, or AWS credentials.
